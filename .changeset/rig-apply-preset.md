Add the `rig.applyPreset` op (MCP `rig_apply_preset`, tool group `rig`): apply a motion preset (walk, run, jump, idle-breathe, swing) to the rig as an animation in one undo step. The `tools/list` byte limit in the server test goes from 82,000 to 84,000 (MCP-04).
