# Contributing

Read [AGENTS.md](AGENTS.md) first: it describes the workflow, commands (`pnpm verify`), coding conventions and the package layering rules. Design context is in [docs/](docs/).

- Run `pnpm verify` before opening a pull request.
- Do not commit absolute home-directory paths or private material; `scripts/privacy-check.sh` checks this.
- Outside contributors can use their own git identity. The pseudonymous commit identity described in AGENTS.md applies only to the maintainer.
