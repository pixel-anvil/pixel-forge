# ADR-009: Godot: engine-neutral baked output plus a driver

- **Status**: Accepted
- **Date**: 2026-10-26

## Context
The first consumer game uses a custom 3D-billboard sprite node whose frames are driven by gameplay, not a free-running clock. A SpriteFrames-only output does not fit it and would create two clocks (R-03, P-03).

## Decision
The primary output is engine-neutral: atlas textures, a frame table and an `origin`, imported from the `.pxf` render cache by an `EditorImportPlugin`. A `PixelForgeDriver` node is the single clock and exposes a game-driven playback API plus `apply(texture, region, offset, flip_h)` adapters; markers and events are generic. `SpriteFrames` output is optional (M1b). An integration contract card (T6.0) pins the interface before implementation. Tests run in Godot 4.6.1 headless in CI.

## Consequences
- The importer needs no knowledge of any specific game node; adapters bridge to them.
- Mirrored animations are flipped at runtime, including markers.
- The addon is installed with `pf godot install`.
