# ADR-006: Browser-first editor; desktop shell deferred

- **Status**: Accepted
- **Date**: 2026-10-26

## Context
The editor is an M2 deliverable. An Electron-first plan had a weak rationale (R-18) and would add packaging cost before the core is proven.

## Decision
The editor is a React 19 + TypeScript + Vite + Zustand web app served by `pf serve`; `pf serve --open` opens it in the default browser. Rendering uses Canvas2D with ImageData blits at integer zoom and overlays on separate layers; WebGL is optional later behind a `CanvasRenderer` interface. A desktop shell is optional and decided in M3 (Electron is the default candidate because the server is Node).

## Consequences
- No packaging work until it is wanted; the same code path serves headless and UI users.
- Browser constraints (file access, keychain) are handled through ports implemented in `server`.
- AI panel is M3 or later; Claude Code via MCP covers it meanwhile.
