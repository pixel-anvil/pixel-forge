# ADR-005: `.pxf` as a zip with a render cache

- **Status**: Accepted
- **Date**: 2026-10-26

## Context
The format must be stable, diffable enough to debug, readable by a small GDScript importer, and safe against partial writes. The game engine should never need our renderer.

## Decision
`.pxf` is a deflate ZIP with fixed entry order: `manifest.json`, `document.json` (sorted keys, no pixel data), `images/<id>.png`, and a `render/` cache (index.json plus flattened per-frame PNGs, updated per frame by input hash; mirrored animations store no PNGs). `pf pack/unpack` convert to a `.pxfd/` folder containing a `.gdignore`. Lockfiles and the journal are never stored beside the file. Encoding uses pinned fflate; saves are atomic; a no-op save leaves `modified` unchanged. Migrations run forward only and old fixtures must keep opening.

## Consequences
- Godot reads only the render cache, so the importer stays tiny.
- File size grows with the cache (can be disabled for scratch files).
- v1 is frozen by fixture; schema evolution goes through migrations.
