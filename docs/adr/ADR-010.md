# ADR-010: Determinism rules

- **Status**: Proposed
- **Date**: 2026-10-26

## Context
Byte-identical output across platforms cannot be verified when codecs, `Math.sin` and timestamps vary (R-12). Rig snapping and goldens require reproducibility. Status is Proposed until fixed-point trig (T1.6) is implemented and the hash suite passes on both CI platforms.

## Decision
Determinism means the same document plus operations yields the same hash of decoded RGBA on macOS, Linux and Windows. Rules: integer maths in the render path; a fixed-point sin/cos table at the angle quantum; no `Math.random` (seeded PRNG only) and no `Date.now()` in pure packages; a pinned pure-JS deflate (fflate) for all encoding; sorted JSON keys, fixed zip order and timestamps; hash decoded pixels, not file bytes.

## Consequences
- Goldens and cross-platform CI hash suites are meaningful.
- Slightly more work in raster/rig (no float trig shortcuts).
- Files are byte-stable within one pf version, not across versions.
