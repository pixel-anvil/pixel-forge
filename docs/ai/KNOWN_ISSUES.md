# Known issues

Add a row when you find a problem you are not fixing in the current card. Remove or mark resolved when fixed.

| ID | Issue | Impact | Workaround/Plan | Since |
|---|---|---|---|---|
| PNG-01 | The `png` decoder ignores unknown chunks, including unknown *critical* ones, which strict PNG would reject. | Exotic or corrupt files may decode without an error. | Acceptable for now (we only read common encoders' output). Reject unknown critical chunks if it ever matters. | 2026-10-26 (T1.8) |
| PNG-02 | For gray/RGB `tRNS` colour keys, pngjs zeroes the RGB of keyed pixels; our decoder keeps the RGB and sets alpha 0 (as libpng does). | Cross-decoder comparisons must ignore RGB under alpha 0. | Documented and pinned by a test. | 2026-10-26 (T1.8) |
| PAL-01 | Built-in palette presets come from Lospec pages that state no licence. | Small legal uncertainty for a public repo. | Colour lists are generally treated as unprotectable data. Each preset credits its author and source URL. Remove a preset if an author objects. | 2026-10-27 (T1.3) |
| CORE-01 | `validate()` (I4) copies the id-scramble constants from `packages/schema/src/ids.ts` to decode id counters. | If the schema's scramble changes, the detector goes silent (it self-checks by re-encoding, so it never goes wrong). | Export a `decodeIdCounter` from schema and use it in core. | 2026-10-27 (T2.2) |
| CORE-02 | Frame-op refusals are `CoreError('BAD_ARGUMENT')` with `details.reason` (unknown-frame, last-frame, …) instead of dedicated codes. | Callers must switch on `details.reason`. | Promote to `CoreErrorCode` values when ops (T5.1) map errors to `OpError`. | 2026-10-27 (T2.2) |
| RIG-01 | Bone `length` is per bone, not per view; the front view reuses the side view's lengths (e.g. the foot). | `bindByOverlap` on the front view uses side lengths. | Add per-view lengths if front/back rigs need them. | 2026-10-27 (T3.2) |
| RIG-02 | `bindParts` skips animated pixel layers (cels with more than one drawing). | Flat per-frame art must be split (T3.5) rather than bound. | Decide in T4.5/T6.4 how animated part art imports. | 2026-10-27 (T3.2) |
| IO-01 | `.pxf` stores indexed images as 8-bit grayscale PNGs without their `transparentIndex`; on read it becomes the first alpha-0 palette entry (else 0). | A store whose IndexedImage used another transparent index re-reads with a different `documentHash`, so `modified` gets bumped. Renders are unaffected. | Add an optional `transparentIndex` to the document's image metadata (additive schema change) when indexed documents are used. | 2026-10-27 (T4.2) |
| IO-02 | Render-cache reuse trusts `renderInputKey`. A mirror's own part overrides (until T3.6) aren't in the key; rig-renderer changes are covered only if `PART_RENDER_VERSION` (rig) or `ROTSPRITE_VERSION` (raster) is bumped (T3.3); a custom renderer must give its own `renderKey`, or the key stays conservative. | A stale cached frame is possible after such changes. | Save without `previous` to force a full re-render. Extend the key in T3.6; bump `PART_RENDER_VERSION` with any pixel-changing part-pipeline change and `ROTSPRITE_VERSION` with any pixel-changing rotation change. | 2026-10-27 (T4.2) |
| IO-03 | `.aseprite` re-import takes frame durations from the file, overwriting durations edited in pixel-forge. | Retiming done in pixel-forge is lost on re-import. | Treat the file as the source of truth for hand-drawn timing; add a `keepDurations` option if needed. | 2026-10-27 (T4.5) |
| IO-04 | Imported part variants are canvas-sized images at (0,0), not trimmed; `run()` in `aseprite-import.ts` is ~600 lines. | RotSprite may do more work per part (unmeasured); harder maintenance. | Measure in the G1 bench; trim with a pivot offset if slow. Split into plan/apply stages when next touched. | 2026-10-27 (T4.5) |
| RIG-03 | Part keys (`variant`/`z`/`visible`) hold the first key backward, like bone channels; an indexed part override's baseHash decodes through the palette. | A `visible: false` key at frame 5 also hides frames 0–4; a palette colour edit stales indexed part overrides. | Intended for now; revisit if authors find it surprising (M1b). | 2026-10-27 (T3.3) |
| CORE-03 | `listStaleOverrides` counts `reason: 'error'` (render failure) as stale; `renderFrame` has no default rig renderer (callers pass `createRigRenderer()`). | Lint/`override_list` must separate errors from stale; ops/CLI must wire the renderer. | Handle in T4.1 and T5.1. | 2026-10-27 (T3.3) |
| GD-01 | `godot/test/addons/pixel_forge` is a symlink to `godot/addons/pixel_forge`; Godot's `ZIPReader` can't open from a buffer. | Windows checkouts need `core.symlinks=true`; in-memory `.pxf` reads need a temp file. | Copy the addon in `run_tests.sh` when Windows support starts. | 2026-10-28 (T6.1) |
