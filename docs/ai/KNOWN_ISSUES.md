# Known issues

Add a row when you find a problem you are not fixing in the current card. Remove or mark resolved when fixed.

| ID | Issue | Impact | Workaround/Plan | Since |
|---|---|---|---|---|
| PNG-01 | The `png` decoder ignores unknown chunks, including unknown *critical* ones, which strict PNG would reject. | Exotic or corrupt files may decode without an error. | Acceptable for now (we only read common encoders' output). Reject unknown critical chunks if it ever matters. | 2026-10-26 (T1.8) |
| PNG-02 | For gray/RGB `tRNS` colour keys, pngjs zeroes the RGB of keyed pixels; our decoder keeps the RGB and sets alpha 0 (as libpng does). | Cross-decoder comparisons must ignore RGB under alpha 0. | Documented and pinned by a test. | 2026-10-26 (T1.8) |
| PAL-01 | Built-in palette presets come from Lospec pages that state no licence. | Small legal uncertainty for a public repo. | Colour lists are generally treated as unprotectable data. Each preset credits its author and source URL. Remove a preset if an author objects. | 2026-10-27 (T1.3) |
| CORE-01 | `validate()` (I4) copies the id-scramble constants from `packages/schema/src/ids.ts` to decode id counters. | If the schema's scramble changes, the detector goes silent (it self-checks by re-encoding, so it never goes wrong). | Export a `decodeIdCounter` from schema and use it in core. | 2026-10-27 (T2.2) |
| CORE-02 | Frame-op refusals are `CoreError('BAD_ARGUMENT')` with `details.reason` (unknown-frame, last-frame, …) instead of dedicated codes. | Callers must switch on `details.reason`. | T5.1: `toOpError` (`packages/ops/src/errors.ts`) maps `unknown-*` reasons to `NOT_FOUND` (with `details.kind`) and every other reason to `REFUSED`, keeping `details.reason`; no new core codes were needed. Op callers branch on `OpError.code`. Close unless a non-op caller needs codes. | 2026-10-27 (T2.2) |
| RIG-01 | Bone `length` is per bone, not per view; the front view reuses the side view's lengths (e.g. the foot). | `bindByOverlap` on the front view uses side lengths. | Add per-view lengths if front/back rigs need them. | 2026-10-27 (T3.2) |
| RIG-02 | `bindParts` skips animated pixel layers (cels with more than one drawing). | Flat per-frame art must be split (T3.5) rather than bound. | `splitRegion` (T3.5) takes one frame's region into a part (one variant per call, e.g. `part:hand_r@frame3`). Decide in T4.5/T6.4 how animated part art imports. | 2026-10-27 (T3.2) |
| IO-01 | `.pxf` stores indexed images as 8-bit grayscale PNGs without their `transparentIndex`; on read it becomes the first alpha-0 palette entry (else 0). | A store whose IndexedImage used another transparent index re-reads with a different `documentHash`, so `modified` gets bumped. Renders are unaffected. | Add an optional `transparentIndex` to the document's image metadata (additive schema change) when indexed documents are used. | 2026-10-27 (T4.2) |
| IO-02 | Render-cache reuse trusts `renderInputKey`. A mirror's own part overrides are never rendered (T3.6 decision), so they are correctly not in the key; rig-renderer changes are covered only if `PART_RENDER_VERSION` (rig) or `ROTSPRITE_VERSION` (raster) is bumped (T3.3); a custom renderer must give its own `renderKey`, or the key stays conservative. | A stale cached frame is possible after such changes. | Save without `previous` to force a full re-render. Bump `PART_RENDER_VERSION` with any pixel-changing part-pipeline change and `ROTSPRITE_VERSION` with any pixel-changing rotation change. | 2026-10-27 (T4.2) |
| IO-03 | `.aseprite` re-import takes frame durations from the file, overwriting durations edited in pixel-forge. | Retiming done in pixel-forge is lost on re-import. | Treat the file as the source of truth for hand-drawn timing; add a `keepDurations` option if needed. | 2026-10-27 (T4.5) |
| IO-04 | Imported part variants are canvas-sized images at (0,0), not trimmed; `run()` in `aseprite-import.ts` is ~600 lines. | RotSprite may do more work per part (unmeasured); harder maintenance. | Measure in the G1 bench; trim with a pivot offset if slow. Split into plan/apply stages when next touched. | 2026-10-27 (T4.5) |
| RIG-03 | Part keys (`variant`/`z`/`visible`) hold the first key backward, like bone channels; an indexed part override's baseHash decodes through the palette. | A `visible: false` key at frame 5 also hides frames 0–4; a palette colour edit stales indexed part overrides. | Intended for now; revisit if authors find it surprising (M1b). | 2026-10-27 (T3.3) |
| CORE-03 | `listStaleOverrides` counts `reason: 'error'` (render failure) as stale; `renderFrame` has no default rig renderer (callers pass `createRigRenderer()`). | Lint/`override_list` must separate errors from stale; ops/CLI must wire the renderer. | Lint done in T4.1 (`rig.overrideError`, own renderer). Ops done in T5.1: every `OpHost` owns one `createRigRenderer()` (`ctx.renderer`, `ctx.renderFrame`); `override.list` (T5.2b, done) reports `error` overrides apart from stale ones; `exportSpritesheet` takes the host renderer as `rig`. | 2026-10-27 (T3.3) |
| GD-01 | `godot/test/addons/pixel_forge` is a symlink to `godot/addons/pixel_forge`; Godot's `ZIPReader` can't open from a buffer. | Windows checkouts need `core.symlinks=true`; in-memory `.pxf` reads need a temp file. | Copy the addon in `run_tests.sh` when Windows support starts. | 2026-10-28 (T6.1) |
| RIG-04 | `attributeEdit` / `attributeEditTx`: a new part override changes the canvas under the frame's existing final overrides, so one whose region (bbox ±1) it touches goes stale; an import into a source animation likewise changes the flipped render under its mirrors' final overrides on that frame. An edited colour that an indexed palette lacks is refused as `BAD_VALUE`/`BAD_RIG` rather than a dedicated reason. | After an import next to an earlier final override (or next to a mirror's, mirrored), that override is listed stale (still applied; the render is exact). `attributeEditTxReport` returns the newly stale ones. The CLI cannot tell a palette miss from a rig fault without reading the message. | Re-base the listed override if the result looks right. Add a dedicated reason when T5.1 maps errors (FR-RIG-24 CLI). | 2026-10-28 (T3.8) |
| OPS-01 | `io` ops change their document through `ctx.transact`, which commits at once; if the handler then throws or returns an output that fails its schema, the call reports an error but the change stays (one undo step). `doc.summary`'s `dirty` compares `store.version` with the version at open/save, so undoing back to the saved state still reads dirty. | A failed io call may still have changed the document; `dirty` can be a false positive. | Call `ctx.transact` last (PLAYBOOKS "Add an op"). Revisit if T5.2b `io.import` needs post-commit work; track a saved history position if `dirty` matters to the editor (M2). | 2026-11-01 (T5.1) |
| OPS-05 | `OpHost.renderer` is typed `RigRenderer`, but `attributeEditTx` needs a `PartRenderer` (the part cache and `frameParts`). `partRenderer(ctx)` (T5.2b) passes the host renderer when it is one (`createRigRenderer()`, what every built-in host owns) and otherwise lets `attributeEditTx` make a fresh one. | A host with a custom `RigRenderer` gets correct but uncached overrides from `pixels.writeGrid`; `override.list`/`import` (T5.2b) hit the same typing. | Type `OpHost.renderer` as `PartRenderer` (additive for callers) when the host interface next changes. | 2026-11-01 (T5.3) |
| RIG-05 | `overlapMask` (T3.5) uses the contract's nearest-sample inverse mapping plus a 3×3 dilation as a model of RotSprite, and only considers the two joint parts: a third part or a pixel layer covering a pixel is not counted as hiding it. | The mask is safe (painting it never changes the rest composite) but not proven to close every gap under every rotation algorithm; `uncovered` can over-report when another part would hide the paint. | Re-run `jointCheck` after painting (the W2b test does); extend the hidden set to all parts when a case needs it. | 2026-11-01 (T3.5) |
| CORE-04 | `splitRegion` (T3.5) makes the new part a part of the rig: it draws in every frame that renders the rig, not only the split frame; the source remainder stays in the flat layer for every frame. | Splitting frame 3 of flat art and playing frame 4 draws the part over frame 4's own flat art. | Key `visible: false` on the other frames, or split the flat layer into per-frame variants and select them with part keys. | OPS-03 | `doc.save` takes the new path's lock (`host.rebind`) before it writes.
