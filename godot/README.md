# Godot addon: `pixel_forge`

Imports pixel-forge `.pxf` files into Godot 4.6 as a `PixelForgeAsset` resource. Contract:
[`docs/contracts/GODOT_INTEGRATION.md`](../docs/contracts/GODOT_INTEGRATION.md); spec FR-GD-01, 02, 04, 05, 07.

**Status:** importer, asset and helpers (T6.1). The driver, adapters and demo come with T6.2 and T6.3.

## Layout

| Path | What |
|---|---|
| `addons/pixel_forge/plugin.cfg`, `plugin.gd` | The addon (versioned in `plugin.cfg`); registers the import plugin. |
| `addons/pixel_forge/pxf_reader.gd` | `PixelForgePxfReader`: `ZIPReader` + JSON + `Image.load_png_from_buffer`. Reads **only** `render/index.json` and `render/<skin>/…png` (FR-GD-05); never `document.json`. Validates the index and reports problems in `error_message`. |
| `addons/pixel_forge/pixel_forge_asset.gd` | `PixelForgeAsset` (the resource), its helpers, `build()` and the shelf packer. |
| `addons/pixel_forge/pixel_forge_import.gd` | `PixelForgeImport`: the import step and the option list, apart from `EditorImportPlugin` so it can be tested outside the editor. |
| `addons/pixel_forge/import_plugin.gd` | The `EditorImportPlugin` for `.pxf` (`_get_resource_type()` is `"Resource"`; textures are embedded in the `.res`). |
| `test/` | A Godot project with GUT 9.6.1 vendored, the fixture `.pxf` files and the tests. |

## Using it

Copy `addons/pixel_forge` into your project's `addons/` folder, enable **Pixel Forge** in Project Settings,
then drop a `.pxf` into the project. Godot imports it, and re-imports it when the file changes.

```gdscript
var asset := load("res://hero.pxf") as PixelForgeAsset
var anim := asset.resolve(&"walk", &"down")        # follows direction_fallback, then "default"
var ms := asset.duration_ms(&"walk", &"down")
var tex := asset.atlases[&"base"]
var rect: Rect2i = asset.frames[anim["frames"][0]]["region"]
```

Import options (FR-GD-04), shown in the Import dock:

| Option | Default | Meaning |
|---|---|---|
| `animations` | empty (all) | Comma-separated `group` or `group/direction` names. The source of an imported mirror is imported too. |
| `skins` | empty (all) | Comma-separated skin names. `base` is always imported. |
| `trim` | on | Crop each frame to its opaque pixels (the union over the imported skins, so every skin shares one layout). A fully transparent frame becomes a 1x1 region. Turn off for nodes that need whole-canvas regions (contract section 8.3). |
| `padding` | 1 | Transparent pixels around each region in the atlas (0 to 64). |

Frames are packed with a shelf packer (tallest first, ties by input order; the atlas is a power-of-two wide, as tall as the shelves need).
All skins share the same layout, so a frame's `region` is valid in every atlas. Frames that share a PNG in the
`.pxf` share a region, but each authored frame keeps its own entry in `frames`.

## Tests

```sh
godot/test/run_tests.sh              # Godot from $GODOT, else `godot` on PATH
godot/test/run_tests.sh -gselect=test_asset_helpers
```

The script imports the project (so the fixtures go through the import plugin), runs GUT headless, and fails
when GUT reports a script that did not load (GUT exits 0 in that case). Tested with Godot 4.6.1.

- **Oracle:** `test_asset_build.gd` crops every atlas region and compares it, byte for byte, with the `render/*.png`
  frames read from the `.pxf` by a plain `ZIPReader` (not the addon's reader), with trim on and off and several paddings,
  for every skin. It also rebuilds each canvas-sized frame from `offset_px` + `region`.
- Other suites: the reader and its error paths, the shelf packer, the import options, skins that differ in extent
  (built from raw PNGs), the asset helpers with hand-worked numbers, and the imported resource.
- **Fixtures:** `test/fixtures/*.pxf` and `expected.json` are generated by `fixtures/src/godot.ts`
  (`pnpm fixtures`; `pnpm fixtures:check` fails when they are out of date). `expected.json` is computed from the generator's
  own rectangle lists, independent of the render cache. Never edit them by hand.
- `test/addons/pixel_forge` is a symlink to `addons/pixel_forge`, so the test project runs the addon as shipped.
- `.godot/` and the `*.pxf.import` files are generated by `godot --import` and are not committed.
