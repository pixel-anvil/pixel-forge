# Synthetic .aseprite fixtures

Generated by Aseprite Lua scripts in `fixtures/src/aseprite/` (run
`fixtures/src/aseprite/make.sh`; override the binary with `ASEPRITE=...`).
Aseprite is used only as a tool; all art is synthetic rectangles. Each file is
under 2 KB.

Oracles per fixture `<name>`:

- `<name>.expected.json`: from `aseprite -b --all-layers --list-layers --list-tags <file> --data <json> --format json-array --sheet <tmp>.png`
  (layers with group/opacity, `frameTags` with 0-based from/to and direction,
  per-frame `duration` in ms). `meta.image` and `meta.version` are stripped so
  no absolute paths remain. The JSON does not carry layer visibility; the hidden
  flag is only in the binary (layer chunk flags bit 0).
- `<name>/<layer>-<frame>.png`: from `--all-layers --save-as "{layer}-{frame}.png"`,
  0-based frame index, one PNG per layer per frame (hidden layers included;
  group layers render empty). Layer names contain `:`, `#`, `@` (invalid on Windows).

Not covered: raw cels (type 0; Aseprite always writes compressed), compressed
tilemap cels (type 3), slices, external files, user data on layers/cels.
Linked cels required `app.command.LinkCels` since the Lua API has no direct
call for them.

## Oracle PNG names

The per-layer PNGs are named `<layer>-<frame>.png` (frames are 0-based). The characters `:`, `#` and `@` in layer names are replaced by `~`, because they are invalid in Windows file names. For example, `part:hand_r#side` becomes `part~hand_r~side-0.png`.
